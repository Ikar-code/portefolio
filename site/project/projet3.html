01

Description

Le Fil du Lord est une plateforme capable de transformer automatiquement des sujets d'actualité en articles publiables.

Le système utilise plusieurs étapes IA spécialisées afin de limiter les erreurs : recherche de sujets, validation des informations, détection des doublons, rédaction journalistique et évaluation avant publication.

02

Ce que le système fait

  • Recherche d'actualitéGemini avec accès Google Search identifie des sujets récents et pertinents.
  • Vérification factuelleLes sujets sont analysés avant rédaction afin de confirmer les informations importantes.
  • Anti-doublons intelligentLe système compare les nouveaux sujets avec les articles existants dans Supabase.
  • Rédaction automatiqueGroq génère un article structuré avec titre, angle éditorial et contenu.
  • Contrôle qualitéGemini attribue un score sur 10 et refuse les articles insuffisants.
  • Retry automatiqueSi un article obtient un mauvais score, le pipeline tente un nouveau sujet ou une nouvelle génération.
  • PublicationLes articles validés sont enregistrés dans Supabase puis affichés sur le site.
03

Pipeline d'exécution

1GitHub Actions lance automatiquement le pipeline via cron.
2Recherche de sujets avec Gemini et Google Search.
3Vérification des doublons et stockage dans Supabase.
4Validation du sujet et création du dossier journalistique.
5Rédaction automatique de l'article.
6Scoring qualité IA avant publication.
7Publication automatique si le score est suffisant.
04

Agents IA utilisés

Agent recherche — Scraping + flux RSS

Le système récupère automatiquement les informations depuis différentes sources grâce au scraping web et aux flux RSS. Les données brutes sont collectées puis transformées en sujets exploitables pour le pipeline éditorial.

Agent vérification — Gemini 2.5 Flash Lite

Analyse les sujets collectés avant rédaction. Il vérifie la cohérence des informations, les dates, les acteurs concernés et les faits disponibles afin de limiter les erreurs et les informations inventées.

Agent rédaction — Qwen3-32B (Groq)

Transforme les informations vérifiées en article journalistique complet. Le modèle génère le titre, l'angle éditorial et le contenu final en respectant la ligne éditoriale du média Le Fil du Lord.

Agent qualité — Gemini 3.1 Flash Lite

Évalue chaque article avant publication avec un score sur 10. Il analyse la fiabilité, la structure, la qualité rédactionnelle et le respect des règles éditoriales avant validation.

05

Architecture technique

Backend

Node.js orchestre les appels IA, la logique métier, les retries et la publication.

Base de données

Supabase stocke sujets, articles, scores, statuts et journaux.

Frontend

React + TypeScript affiche les articles et fournit une interface d'administration.

Déploiement

GitHub Actions automatise l'exécution et Vercel héberge l'application.

06

Points clés

  • Pipeline complet de la recherche à la publication.
  • Double contrôle IA avec vérification et scoring.
  • Système anti-doublons basé sur les événements.
  • Traçabilité complète grâce aux logs.
  • Architecture évolutive pour ajouter de nouveaux agents IA.
